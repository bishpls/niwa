# niwa: a mountain temple

A Japanese mountain temple and its valley, built entirely in code (three.js / WebGL2) and explored in the browser:
the temple precinct and its garden, a cedar approach, a valley of terraced paddies, birds, smoke, water and the day
from dawn to night, with a three-minute reel and its sound.

**Open it:** https://bishpls.github.io/niwa/

It needs a desktop browser with WebGL2 (Chrome or Edge is best) and plenty of memory (16 GB is comfortable). The whole
world is built on your machine as it loads, so the first load takes a while (a progress bar shows where it is).

Controls: drag to orbit, right-drag or shift-drag to pan, scroll to zoom, WASD to fly, 1-9 for viewpoints. The panel
holds the time of day, the reel (with sound) and every setting.

This repository is the site as published (a static bundle). Fonts: Shippori Mincho, SIL Open Font License
(engine/fonts/OFL-shipporimincho.txt); three.js and three-vrm: MIT (engine/vendor/).
